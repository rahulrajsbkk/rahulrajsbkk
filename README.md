### About

I'm a full-stack developer who works in JavaScript end to end — React and React Native on the front, Node.js with PostgreSQL, MongoDB and Redis behind it. I've been shipping products since 2018, and these days I lead a mobile team at **Cloudphysician Healthcare** while still writing code every day.

My day-to-day covers React Native apps, a NestJS backend with real-time chat and an event-driven core, over-the-air updates, and the CI/CD pipelines that ship all of it.

- 🔭 Currently **Technical Lead, Mobile** — React Native, NestJS, team of seven
- 🌱 Poking at Flutter, Kotlin and anything that makes builds faster
